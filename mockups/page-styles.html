2.2Binary search

Remembermid = (low + high) // 2 rounds down. Every trace in this guide uses that rule.

Look at the middle of a sorted list. If the key is smaller, throw away the right half; if it's larger, throw away the left half. Each check halves what's left.

!
Key ideaBinary search only works on sorted data, and it never needs more than about log₂ n checks.

The steps

  1. Set low to the first index and high to the last.
  2. Find mid = (low + high) // 2 and compare the key with items[mid].
  3. Move low or high past mid, and repeat until they cross.
def binary_search(items, key):
    low, high = 0, len(items) - 1
    while low <= high:
        mid = (low + high) // 2      # round down
        if items[mid] == key: return mid
        if items[mid] < key: low = mid + 1
        else: high = mid - 1
    return -1
