# Practice quiz

Each quiz is 10 new questions, built from random values every time. Check each answer as you go to see whether you got it right and why. Your score shows at the top, and **Start a new quiz** gives you a fresh set.

Use the topic boxes to focus on what you need. The questions follow the same conventions as the chapters:

- Binary search uses mid = (low + high) // 2.
- A max-heap stores its root at index 0.
- BFS and DFS take neighbors in alphabetical order.
- Linear probing tries (h + i) % m.

Nothing is saved: a quiz is for practice, not tracking. For questions that count toward your progress, use each chapter's Questions section and the [final practice](22-final-practice.md).
